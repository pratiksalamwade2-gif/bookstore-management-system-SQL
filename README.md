# bookstore-management-system-SQL

**SQL-based bookstore database for managing books, customers, and sales analytics.**

• Designed and implemented a relational database to manage books, authors, publishers, customers, orders, and 
  inventory efficiently.
• Developed complex SQL queries using joins, subqueries, and aggregations to track sales, stock levels, customer 
  purchase history.
• Ensured data integrity through primary/foreign keys and constraints, enabling accurate reporting and smooth
  transaction handling.
